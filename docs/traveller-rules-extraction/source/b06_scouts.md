# B06: Scouts — Rules Extraction

## Source
Classic Traveller Book 6: Scouts (1983), GDW

## Contents

### Scout Service Organization (Page 4)
- Bases covering sectors/subsectors
- Types: Survey, Courier, Support, Combined
- Independent but coordinate with Imperial Navy

### Scout Character Generation (Page 9)
- Enlistment: 6+ (DM+1 for In 8+, DM+1 for college)
- Terms: 10 years
- Office selection: Survey, Courier, Support, Operations
- Skills from assignments and training

### Star System Generation (Page 21)
1. Determine star type and magnitude
2. Generate planets and satellites
3. Determine orbital characteristics
4. Generate UWP for each planet
5. Identify gas giants and asteroid belts
6. Determine starport and base presence
7. Record system data

### UWP Generation (Page 22)
1. Starport (2D6: 2-3=A, 4-5=B, 6-8=C, 9-10=D, 11-12=E, 12=None)
2. Size (1D6: 0-9)
3. Atmosphere (1D6: 0-9)
4. Hydrographics (1D6: 0-90%)
5. Population (1D6: 0-9)
6. Government (1D6: 0-9, A)
7. Law (1D6: 0-9, None)
8. TL (1D6: 0-A)
9. Population in millions
10. World income

### Satellite Generation (Page 36)
- Number based on planet size and type
- Each satellite: Size, orbit, composition, atmosphere
- Moons can be habitable
- Gas giants have multiple satellites

### Stellar Data (Page 41)
- **A**: Blue-white
- **F**: Yellow-white
- **G**: Yellow (most common for habitable worlds)
- **K**: Orange (common for habitable worlds)
- **M**: Red dwarf
- **L**: Brown dwarf
- Binary and multiple star systems possible

### Scout Ship Designs (Page 45)
- 200t scout: J-2 M-3
- 400t survey ship: J-2 M-2
- 800t exploration vessel: J-3 M-2
- All include sensor suites and scientific equipment
