# B07: Merchant Prince — Rules Extraction

## Source
Classic Traveller Book 7: Merchant Prince (1985), GDW

## Contents

### Merchant Lines
- **Large Lines**: Megacorporations and sector-wide lines
- **Small Lines**: Subsector-wide, interface, and fledgling lines
- **Free Traders**: Independent one-ship operations

### Merchant Character Generation (Page 16)
- Six abilities: St, Dx, En, In, Edu, Soc
- College optional (4 years, admission 8+, success 8+, honors 10+)
- Enlistment by merchant line type and homeworld starport
- Terms: 4 years each
- Re-enlistment: 4+ (DM+1 if officer), 12+ required

### Enlistment Requirements (Page 17)
| Line Type | Throw | Starport | Requirements |
|---|---|---|---|
| Megacorporation | 8+ | A | Edu 7+ or college |
| Sector-Wide | 7+ | B | None |
| Subsector-Wide | 6+ | C | None |
| Interface | 6+ | D | None |
| Fledgling | 5+ | E | None |
| Free Trader | 4+ | Any | None |

### Merchant Academy (Page 17)
- For large corporation enlistees without college
- Admission 8+, success 8+, honors 10+
- Graduates receive rank 01, choose department, throw 3x on skill table

### Departments (Page 18)
- **Deck**: Navigation, Astrogation, Ship's Boat, Pilot (Space)
- **Engineering**: Engineering, Electronics, Computer, Gravitics, Drive
- **Purser**: Gunnery, Steward, Security Admin
- **Sales**: Broker, Trader, Admin
- **Administration**: Management, logistics
- **Free Trader**: General duties

### Duty Assignments (Page 20)
- Route, Charter, Speculative Trade, Exploratory Trade
- Smuggling (Free Trader only), Piracy (Free Trader only)
- No Business (Free Trader only), Special Duty

### Trade System (Page 34)
- **Sourceworld**: Where goods are purchased
- **Marketworld**: Where goods are sold
- **Cost**: Amount paid at sourceworld
- **Price**: Amount received at marketworld
- **Selling Price**: Actual amount after Actual Value Table

### Cargo Identification (Page 34)
Format: Starport-TL TradeCodes Cost
Example: C-7 Hi In Cr3,700

### Computing Cost of Goods (Page 40)
- Base: Cr4,000/ton
- Trade class modifiers (each matching classification)
- Tech level: TL x 100
- Starport: A=-1000, C=+1000, D=+2000, E=+3000, X=+5000

### Computing Base Price (Page 41)
- Base: Cr5,000/ton
- Trade class effects from marketworld
- Tech level: (source TL - market TL) x 10% x base price

### Trade Skills (Page 40)
- **Broker**: DM on Actual Value (max +4), costs 5% per level
- **Bribery**: DM+1 per 2 levels, costs 7% per level
- **Trader**: Roll one die in advance, 3 days per level
- **Admin**: DM+1 per level for middle passengers
- **Steward**: DM+1 per level for high passengers
- **Streetwise**: DM+1 per level for low passengers
- **Liaison**: DM+1 per level for minor cargo

### Ship Revenues (Page 41)
- High Passage: Cr10,000/trip
- Middle Passage: Cr8,000/trip
- Low Passage: Cr1,000/trip
- Cargo: Cr1,000/ton
- Mail: Cr25,000/trip

### Trade Goods Types (Page 43)
Raw Materials, Rare Materials, Pharmaceuticals, Novelties, Consumables, High Tech Items, Information, Creative Works, Raw Scientific Data, Imbalance Items, Prototypes
