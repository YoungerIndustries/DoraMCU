# Classic Traveller Rules Database — Gap Analysis & Supplement Recommendations

## Executive Summary

The current Traveller rules database covers **7 source books** with **54 rule entries** and **56 reference table entries**.
This analysis identifies the gaps in coverage and recommends which additional Classic Traveller supplements would most improve the rules database for the Traveller RPG module.

**Key Finding:** The database is missing 4 core B-series rulebooks (B03, B06, B07, B08) and several S-series supplements with significant rules content. The highest-impact additions are **B07 Merchant Prince** (trade system), **B03 Worlds & Adventures** (world generation), and **S09 Fighting Ships** (naval combat).

## 2. Missing B-Series Rulebooks (Highest Impact)

### B03: Worlds & Adventures ⭐⭐⭐⭐⭐ (CRITICAL)

**Why it matters:** This is one of the original 3 core books. It contains the definitive world generation rules, adventure creation system, and animal encounter rules — essential for any Traveller campaign.

**Rules content that would improve the database:**
- **World Generation Tables:** Complete step-by-step world generation (probability, starport, size, atmosphere, hydrographics, population, government, law, tech, alignment, trade codes)
- **Trade Computation:** The full trade computation system (supply/demand tables, commodity prices, profit calculation) — currently only a basic concept exists
- **Speculative Trade:** Rules for speculative trading (buying/selling commodities across worlds)
- **Animal Encounters:** Wildlife encounter tables and rules for wilderness adventures
- **Adventure Creation:** Referee tools for generating adventures, including patron encounters
- **Starport Classes:** Detailed starport class rules (A through F, plus Open and None)
- **Government Types:** Detailed government type descriptions and modifiers
- **Law Level Effects:** How law levels affect gameplay and world characteristics

**Implementation impact:** Would add ~20+ rule entries and 10+ table categories. The trade system alone is a major gap — without it, the game can't support merchant/free trader gameplay.

**Priority:** **Highest** — This is a core rulebook. Missing it means the trade and world generation systems are incomplete.

---

### B06: Scouts ⭐⭐⭐⭐ (HIGH)

**Why it matters:** The definitive source for the Scout Service career and star system generation. Essential for exploration-focused campaigns.

**Rules content that would improve the database:**
- **Scout Service Organization:** Detailed hierarchy, bases, and operations
- **Scout Character Generation:** Expanded career with special schools, college education, new skills
- **Star System Generation:** Complete astronomical system generation (planets, satellites, star types, substellar objects)
- **Scout Ship Design:** Specialized scout ship designs and modifications
- **Survey Operations:** Rules for conducting world surveys
- **New Skills:** Scout-specific skills (e.g., survey-related skills)
- **Star Types:** Detailed star classification and effects on planets
- **Planetary Types:** Expanded planet type tables based on atmosphere, size, and hydrographics

**Implementation impact:** Would add ~15 rule entries and 5+ table categories. The star system generation is critical for the AI mission system.

**Priority:** **High** — Essential for exploration missions and world generation. The current database has basic UWP but lacks the generation mechanics.

---

### B07: Merchant Prince ⭐⭐⭐⭐⭐ (CRITICAL)

**Why it matters:** The definitive trade and commerce system. Without it, merchant gameplay is nearly impossible. This is the most important supplement for completing the trade system.

**Rules content that would improve the database:**
- **Complete Trade System:** Full trade computation with supply/demand tables for all commodities
- **Commodity Tables:** Detailed commodity data (price, volume, weight, availability by world type)
- **Merchant Corporations:** Rules for merchant companies, from megacorporations to free traders
- **Merchant Character Generation:** Expanded merchant career with detailed branches
- **Passenger Operations:** Rules for passenger transport
- **Cargo Operations:** Detailed cargo handling and manifest rules
- **Trade Routes:** Rules for establishing and maintaining trade routes
- **Economic Modifiers:** How world characteristics affect commodity prices
- **Smuggling Rules:** Rules for illegal trade operations

**Implementation impact:** Would add ~25+ rule entries and 15+ table categories. This would transform the trade system from a basic concept to a playable subsystem.

**Priority:** **Highest** — The trade system is one of Traveller's core pillars. Without B07, merchant characters have no meaningful gameplay.

---

### B08: Robots ⭐⭐⭐ (MEDIUM)

**Why it matters:** Adds robot construction and operation rules. Important for TL10+ campaigns but less critical for core gameplay.

**Rules content that would improve the database:**
- **Robot Construction:** Rules for building robots (types, costs, programming)
- **Robot Types:** Combat, service, industrial, and special-purpose robots
- **Robot Programming:** Skill requirements and programming rules
- **Robot Combat:** How robots function in combat
- **Three Laws:** Implementation of Asimov's Three Laws in gameplay
- **TL Requirements:** Technology level requirements for different robot types

**Implementation impact:** Would add ~10 rule entries and 2-3 table categories.

**Priority:** **Medium** — Useful for high-TL campaigns but not essential for core gameplay.

**Implementation impact:** Would add ~20 rule entries (one per ship class) and 3-4 table categories.

**Priority:** **High** — Essential for naval combat. The current database has basic ship design but no pre-designed ship classes.

## 6. Implementation Strategy

### Phase 1: Trade System (B07 + S07 + B03 trade section)

The trade system is the biggest gap. Implementing it requires:

1. **Commodity data:** Add a `TravellerCommodity` entity with fields for name, base price, volume, weight, availability by world type
2. **Trade computation:** Add rules for computing supply/demand based on world characteristics
3. **Profit calculation:** Rules for calculating profit margins
4. **Tables:** Supply/demand tables, commodity price tables

### Phase 2: World Generation (B03 + B06)

The world generation system needs:

1. **Generation tables:** Step-by-step world generation tables
2. **Star system generation:** Astronomical system rules
3. **Planet types:** Expanded planet type tables
4. **Starport classes:** Detailed starport rules

### Phase 3: Naval Combat (S09 + B06 scout ships)

The naval combat system needs:

1. **Ship classes:** Pre-designed ship statistics
2. **Fleet composition:** Rules for fleet deployment
3. **Scout ships:** Specialized scout ship designs

### Phase 4: Optional Systems (B08, SS3, S02)

1. **Robots:** Robot construction and combat rules
2. **Missiles:** Expanded missile rules
3. **Animals:** Wildlife encounter rules

## 7. Current Database Limitations

### What's Missing for a Complete Game

1. **No playable trade system:** The current database has only a basic concept of trade. Without B07/S07/B03, merchant characters cannot meaningfully trade.
2. **No world generation mechanics:** The current database describes the UWP format but doesn't provide the tables to generate worlds.
3. **No pre-designed ships:** The current database has ship design rules but no pre-designed ship classes for quick reference.
4. **No scout career details:** The scout career is mentioned but lacks the detailed rules from B06.
5. **No robot rules:** Robots are mentioned in passing but have no rules.
6. **No animal encounter rules:** Wilderness adventures lack wildlife encounter mechanics.

### What's Already Well-Covered

1. **Combat system:** TAC system, melee, firearms — well covered by B01/B02
2. **Character creation:** Core careers and skills — well covered
3. **Basic ship design:** Hull, drives, fuel — adequately covered by B02/B05
4. **Setting:** Third Imperium and Spinward Marches — covered by S03

## 9. Conclusion

The current rules database provides a solid foundation covering combat, character creation, and basic ship design. However, to support a complete Traveller RPG experience, the following supplements are essential:

1. **B07 Merchant Prince + S07 Traders & Gunboats + B03 Worlds & Adventures** — These three together would add the complete trade system, world generation, and adventure creation rules. This is the single most impactful addition.

2. **S09 Fighting Ships + B06 Scouts** — These would complete the naval combat and exploration systems.

3. **B08 Robots + SS3 Missiles** — These would add optional but useful subsystems.

**Recommended next step:** Obtain B07, B03, and S07 PDFs first, as they provide the trade system — the biggest gap in the current database. Without trade, the game cannot support one of Traveller's core pillars: merchant/free trader gameplay.
